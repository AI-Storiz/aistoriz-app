Setup Instructions:

  1. Go to Google Cloud Console
  2. Create or select a project
  3. Navigate to APIs & Services → OAuth consent screen
  4. Configure the consent screen (External type for testing)
  5. Go to APIs & Services → Credentials
  6. Create OAuth 2.0 Client ID for each platform:
    • Web: Authorized redirect URI: your-domain.com
    • iOS: Bundle ID: host.exp.exponent (for Expo Go)
    • Android: Package name: host.exp.exponent (for Expo Go)
